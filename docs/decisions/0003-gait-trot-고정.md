# 0003 · gait는 trot 고정 — 이산 액션 폐기

> **결정** 2026-07-28 · **상태** 확정

## 결정

HLC 액션에서 **gait 차원을 제거**한다. `cmd[5:8] = trot (0.5, 0, 0)` 고정.
액션은 **8D 연속**이 된다(9D 아님).

## 근거

원안은 gait를 9번째 **이산** 액션(trot ↔ pronk)으로 여는 것이었다. 목적은 **도약**이었다 —
`duty`가 고정 학습되어 조작할 수 없으니 pronk gait가 유일한 도약 후보였다.

P0.5 실측에서 pronk는:
- **몸통을 띄우지 못한다** — 정점 상승 +0.001 m. 발이 떨어지는 것은 다리를 접기 때문이고
  몸통은 오히려 깊게 내려앉는다(z 진폭 0.22 vs trot 0.076).
- **MJX에서는 전복한다** — `pg_z = +0.878`, 로봇이 뒤집혀 눕는다.

**이득이 없는데 실패만 만드는 선택지를 정책에 열어줄 이유가 없다.**
수치는 [03_results.md §2](../03_results.md).

## 파생 결과

- §4.3의 L1 결합 제약은 **trot 마름모만** 쓴다 (`VX_MAX=1.9, YAW_MAX=2.4`).
  pronk를 포함했다면 1.4/1.4로 좁혀야 했다.
- "이산 차원에는 저역필터 금지" 조항이 불필요해졌다.
- gait 전환 채터링 리스크와 그 대응(최소 유지 시간 히스테리시스)이 소멸했다.

## 보존 — 폐기된 이산 액션 구현안

gait를 다시 열게 되면 여기서 시작한다.

- gait는 `{0,0.5}³` 꼭짓점 4개(프리셋)에서만 학습됐으므로 **연속 보간은 분포 이탈**이다.
  `gait_morph` 같은 보간은 쓸 수 없다.
- **저역필터를 걸면 안 된다** — 이산값이 뭉개져 미학습 중간값이 된다.
- Brax PPO는 연속 액션 전제이므로 1차 구현은 **스칼라 1개 + 하드 임계**
  (`g > 0 ? pronk : trot`)로 시작하고, gradient가 죽는 것이 확인되면
  **로짓 4개 → argmax(추론) / Gumbel-softmax(학습)** 로 승격한다.
- HLC가 10 Hz라 매 스텝 토글하는 채터링 위험이 있다 →
  **최소 유지 시간(예: 5 HLC step) 히스테리시스**가 필수다. 관측에 gait 유지 카운터(1D)를
  넣을 계획이었다.
